# Тесты для класса BooksCollector

В этом проекте реализованы юнит-тесты для класса `BooksCollector`, который управляет коллекцией книг, их жанрами и списком избранного.

## Описание тестов

1. **test_add_new_book_adds_book** — проверяет, что новая книга успешно добавляется в коллекцию, если имя валидное.
2. **test_add_new_book_too_long_name** — проверяет, что книга с именем длиннее 40 символов не добавляется.
3. **test_add_new_book_duplicate** — проверяет, что одну и ту же книгу нельзя добавить дважды.
4. **test_set_book_genre_valid** *(параметризованный)* — проверяет, что жанр книги устанавливается корректно для допустимых жанров.
5. **test_set_book_genre_invalid_genre** — проверяет, что жанр не устанавливается, если он не входит в список допустимых.
6. **test_get_books_with_specific_genre** — проверяет, что возвращается список книг с определённым жанром.
7. **test_get_books_for_children_excludes_age_rating** — проверяет, что книги с возрастным рейтингом не попадают в список книг для детей.
8. **test_add_book_in_favorites** — проверяет, что книгу можно добавить в избранное, если она есть в коллекции.
9. **test_add_book_in_favorites_not_in_collection** — проверяет, что нельзя добавить в избранное книгу, которой нет в коллекции.
10. **test_delete_book_from_favorites** — проверяет, что книгу можно удалить из избранного.
